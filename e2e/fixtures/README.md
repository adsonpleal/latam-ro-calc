# Visual fixtures

`monster-21067.png` is the first frame of the game's Dummy idle sprite from
<https://assets.latam-tools.com.br/image?job=21067&action=0>, captured on 2026-09-30.
It retains the source image's dimensions and transparency. The appearance suite
serves this static PNG instead of the APNG, since disabling CSS animations does
not pause animated images. Production assets and rendering are unchanged.

`item-13186.png` is the collection illustration for [Aluguel] Espingarda TE from
<https://www.divine-pride.net/img/items/collection/thROG/13186>, captured on 2026-10-06.
The item-search appearance test serves this unchanged PNG so a temporary external
image failure does not hide the illustration in a screenshot. Production requests
and missing-image behavior are unchanged.
